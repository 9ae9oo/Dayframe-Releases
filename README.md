# Dayframe

바이브 코딩으로 만든,
ADHD나 집중을 잘 못하는 창작자를 위한 일정 관리 Electron 데스크톱 앱입니다.

생각나는 대로 일단 적고(인박스), 나중에 날짜와 시간에 끼워 넣고(일간·주간·월간),
작업하는 동안에는 작은 창 하나만 띄워 두는 흐름을 목표로 합니다.

아직 UI/UX에서 부족한 점이 많습니다.

사용된 에이전트 및 스킬
- CODEX : GPT 6 Astra / GPT 5.6 Sol
- Claude CODE : Opus 5 / Sonnet 5
- Cursor : cursor Grok 4.6
- Cline : deepseek V4.1 Flash
- VS code github Copilot

## 설치

1. 오른쪽 **Releases**에서 가장 위(Latest)의 `Dayframe-Setup-<버전>.exe`를 내려받습니다.
2. 실행해서 설치합니다. 코드 서명이 없어서 Windows가 "알 수 없는 게시자" 경고를 띄울 수 있습니다.
   **추가 정보 → 실행**을 누르면 설치됩니다.
3. 새 버전이 나오면 앱이 알려 줍니다. 내려받기와 설치는 **설정 › 일반**에서 직접 눌렀을 때만 진행됩니다.

- 지원: Windows (macOS는 준비 중)
- 기록은 내 PC에만 저장됩니다: `%APPDATA%\Dayframe`

# 기본 기능

앱을 켜면 인박스만 열립니다. 왼쪽 세로 메뉴의 아이콘을 누르면 필요한 도구가 **각자 따로 떨어진 작은 창**으로 열립니다.
필요한 창만 꺼내 두고, 나머지는 닫아 두는 방식입니다.

1. 인박스 Inbox
   - 일단 시간을 생각하지 않고 무엇을 할지 적어두는 브레인 덤프 리스트입니다.
   - 갤럭시 휴대폰의 캘린더처럼 하단의 빠른 입력창에 "오늘 오전 10시 편집자와의 회의"라고 쓰면 해당 일정이 등록됩니다.
   - 오전·오후·저녁처럼 하루의 시간대별로 나눠서 보여 줍니다.
   - 색 카테고리와 `#태그`로 할 일을 묶을 수 있습니다.
   - 드래그로 일간 / 주간 / 월간에 배치할 수 있습니다.
   - 완료된 목록은 하단에 따로 정리됩니다.

2. 일간 / 주간 / 월간 일정
   - 세 화면 모두 따로 창으로 열 수 있어서, 인박스 옆에 주간 창을 붙여 두고 쓸 수 있습니다.
   - 인박스에서 할 일을 끌어다 원하는 날짜·시간에 놓으면 일정이 됩니다.
   - 한국 공휴일이 표시됩니다.

3. 할 일·일정 상세
   - 카드를 누르면 창 오른쪽에 상세 칸이 열리고, 고친 내용은 바로 저장됩니다.
   - 체크리스트를 달아서 큰 일을 작은 단계로 쪼갤 수 있습니다. (예: 체크 1/4)
   - 반복 일정을 만들 수 있고, 반복 일정의 체크리스트를 고칠 때는 「이 일정만 / 전체 일정」 중에 고릅니다.
   - 다른 날짜로 옮기기: 종일·오전·오후·저녁 또는 정확한 시간으로 옮길 수 있습니다.

4. 작품 Workflow
   - 진행 중인 작품(원고, 외주 등)을 공정 단계별로 관리합니다.
   - 마감일을 정해 두고 순서를 바꿔 가며 볼 수 있습니다.

5. 메모
   - 트위터 형태의 빠르게 적어 두는 메모장입니다. 한글 입력에 맞춰 다듬었습니다.

6. 해빗 Habit
   - 매일 반복하는 습관을 칸으로 체크합니다.
   - 정한 시간에 알림을 받을 수 있습니다.

7. 시간 도구
   - **시계**: 작게 띄워 두는 시계 창입니다.
   - **작업 시간**: 오늘 어떤 프로그램을 얼마나 썼는지 자동으로 모아 보여 줍니다. (처음에는 꺼져 있고, 설정에서 켜야 모읍니다. 프로그램 이름과 창 제목만 기록하며 내 PC 밖으로 보내지 않습니다.)
   - **뽀모도로 타이머**: 집중·휴식 시간을 번갈아 재는 작은 타이머 창입니다.

8. 포커스 모드
   - 작업할 때 인박스를 폭 240짜리 작은 창으로 줄여서, 지금 할 일과 타이머만 보이게 합니다.
   - 정한 간격(최대 4시간)마다 집중 안내를 띄울 수 있습니다.

9. 음악
   - YouTube 재생목록을 등록해서 작업하면서 들을 수 있습니다. (인터넷 연결 필요)

10. 설정
    - 색상 테마를 고를 수 있습니다.
    - 기록을 백업 파일로 내보내고 다시 불러올 수 있습니다.
    - 작업 표시줄 트레이 아이콘에서 창을 모두 열거나 닫을 수 있습니다.

# 차후 개발 예정
순서와 내용은 만들면서 바뀔 수 있습니다.

### 만드는 중

1. 노트
   - 메모와 별개인 글쓰기 편집기입니다.
   - 제목·목록·체크박스·표·이미지·형광펜을 버튼으로 넣을 수 있습니다. (Markdown 기호를 몰라도 됩니다)
   - 노트를 「노트 모음」으로 묶어서 정리합니다.
   - Markdown·TXT·HTML·이미지(PNG/JPG)로 내보내고, 서식을 살린 채 복사할 수 있습니다.

2. macOS 버전
   - Mac(Apple Silicon)용 테스트 빌드까지 만들었고, 실제 Mac에서 확인하는 중입니다.

### 검토 중 (아직 만들지 정하지 않음)

- **트레이 작업바**: 작업 표시줄 근처에 작게 띄워서 지금 할 일을 바로 체크하는 막대
- **서브 모니터 대시보드**: 두 번째 모니터에 전체 화면으로 띄우는 위젯 모음
- **ChatGPT 연동**: 인박스에 쌓인 할 일의 우선순위나 일정 정리를 AI가 도와주는 기능 (별도 서버 없이)
- **휴대폰·외부 캘린더 연동**: Google 캘린더 등과 일정을 주고받는 기능
- **업데이트 안내**: 새 버전을 설치한 뒤 무엇이 바뀌었는지 보여 주는 안내
